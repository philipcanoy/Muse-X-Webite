# Muse-X website

Statische website — elke pagina is één zelfstandig HTML-bestand (afbeeldingen, audio en scripts zitten erin).

- `index.html` — homepage
- `gitaarlessen.html`, `gitaarles-voor-kinderen.html`, `proefles.html`, `docent.html`, `faq.html`, `contact.html`

## Online zetten met GitHub Pages
1. Maak een nieuwe repository op GitHub.
2. Upload **alle bestanden uit deze map** naar de hoofdmap van de repository.
3. Settings → Pages → branch `main`, map `/ (root)` → Save.
4. Na een minuutje staat de site op `https://<gebruikersnaam>.github.io/<repo-naam>/`.

Laat de bestandsnamen ongewijzigd, anders werken de links tussen de pagina's niet.
